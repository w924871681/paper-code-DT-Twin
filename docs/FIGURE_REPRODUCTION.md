# Figure reproduction

## Canonical command

From the repository root:

```powershell
python .\scripts\generate_paper_outputs.py
```

This is the only formal reviewer entry point. The maintained plotting
implementation is `reporting/final_figures.py`.

## Acceptance checks

The generator:

- emits vector PDFs without Type 3 fonts or embedded raster panels;
- emits 600-DPI color PNGs and grayscale previews;
- checks text bounds and adjacent tick-label overlap;
- checks each Fig. 9--11 generator role against its output filename and
  validates the Supplement filename/caption mapping;
- checks deployment-radar data rows, plotted methods, and legend entries are
  all equal, and requires MSA-DTI to be present;
- verifies Fig. 1--5 dimensions and checksums;
- verifies the current manuscript Fig. 5 H-Meta-NAS labels against the
  canonical result row;
- records hashes for every source and output;
- does not train models, adapt candidates, select candidates, or recompute
  confidence intervals.

Fig. 6 categories are post-selection test-MSE audit labels. The same
categories appear in both panels and do not affect selection. Fig. 11 held-out
test cases are not used to select the retained configuration count, update
budget, or threshold. The auxiliary radar is retained for reproducibility but
does not occupy a Supplement figure number.
